# Product Marketing Context

*Last updated: 2026-02-10*

## Product Overview
**One-liner:** Neore is one AI workspace that replaces six subscriptions — chat, images, video, documents, code, and research from 30+ models.
**What it does:** Neore combines every major AI model (GPT-4, Claude, Gemini, FLUX, Runway, Luma, and more) into a single workspace. Users can chat, generate images, create videos, write documents in a side-by-side canvas, run code, and do multi-step research — all from one conversation thread, one account, one price.
**Product category:** AI workspace / AI aggregator platform
**Product type:** SaaS (freemium)
**Business model:** Freemium with credit-based tiers. Free (50 prompts/mo), Pro ($20/mo or $16/mo annual), Team ($30/mo or $25/mo annual), Enterprise (custom).

## Target Audience
**Target companies:** Individuals, freelancers, startups, creative agencies, and mid-size teams that currently pay for multiple AI tools.
**Decision-makers:** Individual creators, content marketers, designers, developers, team leads, CTOs at small-mid companies.
**Primary use case:** Consolidating multiple AI subscriptions into one workspace where models work together instead of in silos.
**Jobs to be done:**
- "I need to use the best AI model for each task without managing six accounts"
- "I want to compare outputs from different AI models before committing to one"
- "I need to go from idea to finished content (text + images + video) without switching tools"
**Use cases:**
- Content creation (draft → canvas → images → publish)
- Market research (Deep Research with cited sources)
- Creative direction (compare image/video outputs across providers)
- Technical work (code with AI → execute Python → document in canvas)
- Team collaboration (shared threads, branching, centralized insights)

## Problems & Pain Points
**Core problem:** AI power is fragmented across dozens of separate tools, each with its own subscription, login, and interface. Using the best model for each task means paying $100+/month and constantly switching tabs.
**Why alternatives fall short:**
- ChatGPT only gives you one model family — no images from FLUX, no video from Runway
- Midjourney is images only — no chat, no documents, no code
- Runway is video only — you still need a chat tool and an image tool
- No existing tool lets you compare outputs across providers in one thread
**What it costs them:** $100+/month in subscriptions, hours of tab-switching per week, lost context when moving between tools, inability to compare and pick the best result.
**Emotional tension:** Frustration of "there must be a better way." Anxiety about which AI tool to bet on when new models launch monthly. Overwhelm from managing multiple accounts.

## Competitive Landscape
**Direct:** Poe (by Quora) — multi-model chat but no image/video generation, no canvas, no code execution, no deep research.
**Direct:** TypingMind — multi-model frontend but BYO-API-key, no built-in media generation, technical setup required.
**Secondary:** ChatGPT Plus ($20/mo) — strong single-model experience, but locked to OpenAI models. No FLUX, no Runway, no Luma.
**Secondary:** Midjourney ($10-30/mo) — best-in-class image generation, but no chat, no documents, no video.
**Indirect:** Using 5-6 separate tools (ChatGPT + Midjourney + Runway + Claude + Stable Diffusion) — works but expensive, fragmented, no shared context.

## Differentiation
**Key differentiators:**
- 30+ models across text, image, and video in one workspace (no competitor offers this breadth)
- Mid-conversation model switching — compare answers without leaving the thread
- Integrated canvas editor for long-form content alongside chat
- Built-in code execution (Python sandbox with visual output)
- Deep Research tool with multi-step analysis and cited sources
- MCP server support for plugging in any external tool or API
**How we do it differently:** Instead of building one proprietary model, we aggregate the best models from every provider and make them work together in a single conversation thread.
**Why that's better:** Users always have access to the best model for each task. When a new model launches, it appears in Neore — no new subscription needed.
**Why customers choose us:** Cost savings (one plan vs six), workflow efficiency (no tab-switching), and the ability to compare before committing.

## Objections
| Objection | Response |
|-----------|----------|
| "I already pay for ChatGPT Plus, why switch?" | ChatGPT gives you one model family. Neore gives you GPT-4 + Claude + Gemini + FLUX + Runway + 25 more. You keep GPT-4 and gain everything else — for the same price. |
| "How's the quality compared to using each tool directly?" | We use the official APIs. Same models, same quality. The difference is you access them from one workspace instead of six tabs. |
| "Is my data safe with a third party?" | We never train on your data. GDPR compliant, encrypted, full export anytime. Your conversations and creations stay yours. |

**Anti-persona:** Users who only need one AI model and never use images/video/code. Power users who want to fine-tune models or need enterprise-grade API access for production systems.

## Switching Dynamics
**Push:** Paying $100+/month across multiple AI tools. Losing context every time you switch between ChatGPT and Midjourney. New models launching monthly and not knowing which subscription to add next.
**Pull:** One price for everything. Compare outputs side by side. Chat, images, video, documents, and code in one thread. Free tier to try before committing.
**Habit:** "I already know how ChatGPT works." Existing workflows built around specific tools. Saved prompts and conversation history in current tools.
**Anxiety:** "Will it be as good as using each tool directly?" "What if they shut down or raise prices?" "Is my data safe with a smaller company?"

**Words to use:** workspace, models, generate, create, compare, switch, thread, canvas, one subscription, free to start
**Words to avoid:** leverage, utilize, synergy, cutting-edge, revolutionary, disruptive, AI-powered (redundant — the whole product is AI), seamless, robust, MCP (use "integrations" or "plug in your tools" in marketing copy)
**Glossary:**
| Term | Meaning |
|------|---------|
| Thread | A conversation with full history, branching, and model switching |
| Canvas | Side-by-side document editor that works alongside chat |
| Deep Research | Multi-step automated research tool that cites sources |
| Model switching | Changing which AI model responds mid-conversation |
| MCP | Model Context Protocol — open standard for connecting external tools (avoid in marketing copy) |

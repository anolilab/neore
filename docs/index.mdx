# Features Overview

Welcome to Neore Chat - an AI-powered chat application with advanced conversation management, file storage, and organization features.

## Core Features

Neore Chat provides a comprehensive set of features designed to enhance your AI interaction experience:

### [Authentication](/docs/authentication)

Secure authentication with multiple sign-in options:
- Email/Password authentication
- Google Sign-In (OAuth)
- Anonymous guest access
- Two-factor authentication (TOTP) with backup codes
- Registration is invite-only; guest access is not

[Learn more about authentication →](/docs/authentication)

### [Chat](/docs/chat)

Powerful AI chat capabilities with advanced thread management:
- Multiple AI model providers (OpenAI, Anthropic, Google, etc.)
- Three thread types: Normal, Temporary, and Stateless
- Rich message formatting with Markdown, code highlighting, and diagrams
- File attachments and audio transcription
- AI-powered follow-up suggestions to continue conversations
- Thread organization with tags, pinning, and hierarchy

[Learn more about chat features →](/docs/chat)

### [Vault](/docs/vault)

File management and storage system:
- Upload files via button or drag-and-drop
- Organize files with tags and search
- Grid and list view options
- Related files display

[Learn more about vault →](/docs/vault)

### [Settings](/docs/settings)

Customize your experience:
- Account and profile management
- Chat model preferences
- App customization options
- API key management
- Organization settings

[Learn more about settings →](/docs/settings)

### [Organizations](/docs/organizations)

Team collaboration features:
- Create and manage organizations
- Invite team members
- Role-based permissions
- Multi-organization support

[Learn more about organizations →](/docs/organizations)

### [Prompts](/docs/prompts)

Create and manage reusable prompt templates:
- Dynamic variables with `{{variableName}}` syntax
- Model settings and configurations
- Prompt optimization and history
- Organization with tags and favorites

[Learn more about prompts →](/docs/prompts)

### [Skills](/docs/skills)

Custom AI behaviors invoked by slash commands:
- Define instructions, variables, and tool configurations once
- Invoke with `/skill-name arg=value` in the chat composer
- Autocomplete shows all your enabled skills as you type
- Skills inject specialized context so the AI follows your exact workflow

[Learn more about skills →](/docs/skills)

### [Spreadsheets](/docs/spreadsheets)

Create, edit, and export spreadsheet documents within conversations:
- AI generates interactive spreadsheets you can edit in-place
- Import data from XLSX/XLS files
- Download as CSV or XLSX
- Inline thumbnail previews in chat messages

[Learn more about spreadsheets →](/docs/spreadsheets)

### [Pins](/docs/pins)

Save and annotate important content from text model conversations:
- Pin full messages or specific text selections
- Add personal notes to each pin
- View all pins in the right sidebar Pins tab, scoped per thread
- Edit pinned excerpts and delete pins you no longer need

[Learn more about pins →](/docs/pins)

### [Projects](/docs/projects)

Group related chats under shared context and defaults:
- One context field the AI sees in every chat in the project
- Default model, reasoning effort, and enabled tools for new chats
- Colour and icon for quick identification in the sidebar
- Move existing chats in or out at any time

[Learn more about projects →](/docs/projects)

### [Workflows](/docs/workflows)

Build multi-step AI pipelines on a visual node canvas:
- Chain image, video, text, and audio models together
- 24 node types including ControlNet, style and character references, inpaint, upscale
- Nine starter templates, or generate a whole workflow from a prompt
- Live multi-user editing, version history, and a community gallery to fork from

[Learn more about workflows →](/docs/workflows)

### [Design Canvas](/docs/design-canvas)

AI-generated visual designs you can edit by hand:
- 37 platform presets (Instagram, LinkedIn, YouTube, A4 flyer, business card, …)
- 16 visual styles from minimal to brutalist
- Full editor: text, shapes, freehand, layers, properties, undo/redo
- Ask the AI to revise a design, or apply background removal and upscaling to the canvas

[Learn more about the design canvas →](/docs/design-canvas)

### [AI Tools](/docs/tools)

A suite of 50+ built-in tools the AI can use automatically:
- Web search, deep research, and academic search
- Image generation/editing, video generation, music generation, and vision analysis
- Code execution, presentations, designs, and translations
- People/company search, finance tools, and more

[Learn more about AI tools →](/docs/tools)

### [Browser Automation](/docs/browser)

Automate web browsing with a cloud-powered browser:
- Navigate, click, type, screenshot, and extract data
- Sessions persist per thread for multi-step browsing
- Cloud-based — no local browser required

[Learn more about browser automation →](/docs/browser)

### [Triggers](/docs/triggers)

Automate AI agent execution without manual interaction:
- Schedule triggers with cron expressions and timezone support
- Webhook triggers for external service integrations (Stripe, GitHub, Zapier)
- Each trigger creates a thread with Deep Work mode (25 iterations)

[Learn more about triggers →](/docs/triggers)

### [Knowledge Base](/docs/knowledge-base)

Upload documents to give the AI persistent context:
- Upload PDFs, DOCX, TXT, and other documents
- Attach knowledge bases to specific threads
- Semantic search for relevant context (RAG)
- Improves response quality for your domain

[Learn more about knowledge base →](/docs/knowledge-base)

### [Memory](/docs/memory)

The AI remembers facts about you across conversations:
- Automatic fact extraction from conversations
- Smart deduplication and belief revision
- Personalized responses that improve over time
- Full control — view, delete, or disable at any time

[Learn more about memory →](/docs/memory)

### [Chat Import](/docs/chat-import)

Import your conversation history from other AI platforms:
- Supports ChatGPT, Google Gemini, and Claude exports
- Auto-detects provider from file structure
- Server-side processing with real-time progress
- Handles JSON and ZIP export files

[Learn more about chat import →](/docs/chat-import)

### [Messenger Integration](/docs/messenger)

Chat with the AI from Telegram, Slack, or Discord:
- Connect your messenger account from settings
- Messages create threads with a platform badge in the thread list
- AI auto-responds on the platform
- Pause or disconnect connections at any time

[Learn more about messenger integration →](/docs/messenger)

### [Privacy & GDPR](/docs/privacy)

Manage your privacy and data rights:
- Consent preferences for cookies and data processing
- Data access summary (GDPR Article 15)
- Data export in JSON format (GDPR Article 20)
- Account deletion (GDPR Article 17)
- DPO contact information

[Learn more about privacy & GDPR →](/docs/privacy)

### [MCP Servers](/docs/mcp)

Extend the AI with external tools and interactive UIs:
- Connect Model Context Protocol servers for additional tools
- Supports Streamable HTTP and SSE protocols
- MCP Apps render interactive UIs inside tool call cards
- Encrypted authentication headers for secure connections

[Learn more about MCP servers →](/docs/mcp)

### [Keyboard Shortcuts](/docs/keyboard-shortcuts)

Efficient navigation and actions:
- Command Palette (`Ctrl+K`) for quick navigation and actions
- Quick thread navigation
- Slash commands (`/model`, `/prompt`, `/skill-name`)
- Customizable shortcuts
- Power user features

[Learn more about keyboard shortcuts →](/docs/keyboard-shortcuts)

## Quick Start

Get started with Neore Chat in minutes:

1. **Sign In**: Open your invitation link and choose email/password or Google Sign-In — or start as an anonymous guest, which needs no invitation
2. **Start Chatting**: Create a new thread and begin conversing with AI models
3. **Organize**: Use tags, pinning, and folders to organize your conversations
4. **Customize**: Adjust settings to match your preferences

:::tip New User?
Check out the [Chat Features](/docs/chat) guide for a detailed walkthrough of getting started with conversations.
:::

## Feature Highlights

- **320+ AI Models**: Switch between OpenAI, Anthropic, Google, Moonshot, DeepSeek, xAI, Meta, Mistral, and many more providers
- **50+ Built-in Tools**: Web search, deep research, image/video/music generation, code execution, browser automation, translations, finance tools, and more
- **Deep Work Mode**: Let the AI chain up to 25 tool-use iterations for complex multi-step tasks
- **Workflows**: Build multi-step image and video pipelines on a visual node canvas, with live collaboration and a fork-able community gallery
- **Projects**: Group chats under shared context, a default model, and default tools
- **Browser Automation**: Automate web tasks with a cloud-powered browser (navigate, click, type, screenshot, extract)
- **Triggers**: Automate agent execution on cron schedules or via webhooks from external services
- **Knowledge Base**: Upload documents for persistent AI context via semantic search (RAG)
- **Memory**: The AI learns and remembers facts about you across conversations
- **MCP Servers**: Extend the AI with external tools and interactive UIs via Model Context Protocol
- **Canvas Artifacts**: AI-generated documents, spreadsheets, code, images, designs, and presentations with version history
- **Design Canvas**: Editable visual designs with 37 platform presets and 16 styles
- **Thread Types**: Choose between normal persistent threads, temporary auto-expiring threads, or stateless threads without history
- **Thread Sharing**: Share threads via email invitations with read/write/admin permissions
- **Rich Formatting**: Markdown support, code syntax highlighting, and Mermaid diagrams
- **Prompt Templates**: Create reusable prompts with dynamic variables and model settings
- **Prompt Optimizer**: Rewrite your prompt or system prompt in one of several styles, then refine with feedback
- **System Prompt Presets**: Save named system prompts and apply them per thread
- **Skills**: Custom AI behaviors invoked with `/skill-name` slash commands
- **Pins**: Save and annotate important messages and text selections
- **Spreadsheets**: AI-generated spreadsheets with XLSX import/export and inline previews
- **File Management**: Upload and organize files in your personal vault
- **Chat Import**: Bring conversations from ChatGPT, Gemini, and Claude into Neore Chat
- **Messenger Integration**: Chat with the AI from Telegram, Slack, or Discord using your own bot tokens
- **BYOK (Bring Your Own Key)**: Use your own API keys for AI providers, search tools, and messenger bots
- **Extended Thinking**: View the AI's reasoning process with Claude and DeepSeek thinking models
- **Invite-Only Registration**: Accounts require an invitation; anonymous guest access does not
- **Two-Factor Authentication**: TOTP with backup codes
- **GDPR Compliance**: Full GDPR rights including data export and account deletion
- **Team Collaboration**: Work with organizations, teams, and role-based permissions
- **Keyboard Navigation**: Efficient keyboard shortcuts with Command Palette and customization

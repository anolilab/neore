# Pins

Pins let you save important messages or specific text selections from a conversation to a dedicated sidebar panel. Add notes to each pin to capture your thoughts, and revisit them without scrolling through the full thread.

:::note
Pins are available in text model conversations only. Threads using image, video, or voice generation models do not show the Pins tab.
:::

## Quick Start

1. **Select text** in any message and click **Pin** in the selection toolbar
2. **Or** hover a message and click the **pin icon** to save the full message
3. Open the **Pins tab** (📌) in the right sidebar to see all pins for the current thread

## Pinning Content

### Pin a Text Selection

Select any text in a message — a paragraph, a code block, a key sentence — and a small toolbar appears above the selection with two actions:

- **Pin** — saves the selected text as a pin
- **Copy** — copies the selection to clipboard

After pinning, the Pins sidebar tab opens automatically so you can immediately add a note.

### Pin a Full Message

Hover over any message to reveal the message action icons, then click the **pin icon** (📌). The entire message content is saved as a pin labeled "Full message pinned".

## Pins Sidebar Tab

Open the Pins tab from the right sidebar panel of any thread. Pins are **per-thread** — each thread has its own set of pins, visible only in that thread's sidebar.

Each pin card shows:

- The pinned text excerpt (or "Full message pinned" for full-message pins)
- **You** / **AI** label and relative timestamp (e.g. "5m ago")
- A **note field** for your annotations
- **Edit** and **Delete** action buttons

Long excerpts are automatically collapsed with a fade. Click the chevron to expand or collapse.

## Adding Notes

Click inside the note field at the bottom of any pin card and start typing. Notes are saved automatically as you type — no need to press Save.

Notes support plain text. Use them to:
- Record why you pinned something
- Add context or follow-up questions
- Track action items from the conversation

## Editing a Pin

Click the **pencil icon** on a pin card to open the excerpt editor. You can rewrite or trim the pinned text in the editor, then click **Save**. This does not affect the original message — only the saved excerpt in the pin.

## Deleting a Pin

Click the **trash icon** on a pin card to remove it. Deletion is immediate and cannot be undone.

## Common Use Cases

**Capturing key AI responses**
Pin important answers, explanations, or generated content so you can reference them later without scrolling back through a long thread.

**Research and note-taking**
Select specific sentences or data points from AI responses, pin them, and add notes linking them to your research context.

**Action items**
Pin messages that contain tasks or decisions, and use the note field to track status or add details.

**Code snippets**
Select and pin code blocks from AI responses. The pin renders the code with syntax formatting for easy reading.

## Troubleshooting

**Issue**: Pins tab is not visible in the sidebar
- **Solution**: Pins are only available in **text model** threads. Switch to a text AI model (e.g. GPT-4o, Claude) to use pins — image, video, and voice generation threads do not show the Pins tab

**Issue**: Pin button doesn't appear when selecting text
- **Solution**: Make sure you select text inside a message bubble, not in the composer

**Issue**: Pins not showing in the sidebar
- **Solution**: Make sure the **Pins** tab is selected in the right sidebar panel

**Issue**: Note changes are lost
- **Solution**: Notes auto-save after a short delay — wait a moment before navigating away

# Privacy & GDPR

Neore Chat is committed to protecting your privacy and providing full compliance with GDPR (General Data Protection Regulation) and other data protection laws. This page explains your privacy rights and how to exercise them.

## Quick Start

Access Privacy & Data settings:

1. Navigate to Settings → Privacy & Data
2. Review your privacy options
3. Manage consent preferences
4. Request data export or account deletion if needed

## Overview

The Privacy & Data section provides comprehensive tools for managing your personal data:

- **Privacy Policy** - Review how we handle your data
- **Consent Preferences** - Control cookie and data processing consent
- **Data Access Summary** - View summary of your personal data
- **Data Export** - Download all your personal data
- **Chat Import** - Import conversations from other AI platforms
- **Account Deletion** - Permanently delete your account and data
- **DPO Contact** - Contact our Data Protection Officer

## Data Export (Article 20 - Right to Data Portability)

Download a complete copy of all your personal data in JSON format.

### What's Included in Export

The export is a single JSON file containing:

| Section | Contents |
|---|---|
| `dataSubject` | Your user id and email |
| `profile` | Account information, email, name |
| `settings` | User preferences and AI settings |
| `conversations` | All threads, with their messages |
| `files` | File metadata (file contents are stored separately) |
| `prompts` | Saved prompts and their edit history |

It also carries an `exportDate` and an `exportVersion`.

:::note
Some data is **erased** on account deletion but is not currently included in the
export file — memories, pins, projects, skills, triggers, and knowledge base
files. If you need a copy of those before deleting your account, retrieve them
from their own pages first. This is a gap in data portability coverage, not in
erasure coverage: deletion removes them.
:::

### Requesting an Export

**How to Request:**
1. Go to Settings → Privacy & Data
2. Click "Request Data Export"
3. Export request is submitted
4. You'll receive an email when ready

**Export Process:**
1. Request submitted
2. Data collection begins (may take a few minutes)
3. Progress shown in real-time
4. Export file generated
5. Email notification sent
6. Download link available for 7 days

**Export Status:**
- **Pending:** Request submitted, waiting to start
- **Processing:** Data collection in progress
- **Completed:** Export ready for download
- **Failed:** Export encountered an error
- **Cancelled:** Export was cancelled

**Downloading Export:**
1. When export is ready, click "Download Export"
2. File downloads as JSON
3. Open with any text editor or JSON viewer
4. Download link expires after 7 days

**Export Format:**
```json
{
  "exportVersion": "1.0",
  "exportDate": "2026-01-02T10:30:00.000Z",
  "dataSubject": {
    "id": "user_123",
    "email": "user@example.com"
  },
  "profile": { ... },
  "settings": { ... },
  "conversations": [ ... ],
  "files": { ... },
  "prompts": [ ... ],
  "usageHistory": [ ... ]
}
```

**Features:**
- Complete data portability
- JSON format for easy processing
- Secure download links (7-day expiry)
- Email notifications
- Progress tracking
- Can cancel stuck exports

## Chat Import

Import your conversation history from ChatGPT, Google Gemini, or Claude into Neore Chat.

**Supported Providers:**
- ChatGPT (export ZIP or `conversations.json`)
- Google Gemini (Google Takeout ZIP)
- Claude (exported JSON)

**How to Import:**
1. Export your data from the source provider
2. Go to Settings → Privacy & Data
3. Click **Select File** under Import Conversations
4. Review the preview and click **Import All**

The import runs entirely server-side — you can close the browser and it will continue processing. Progress is shown in real time when you return to the page.

See [Chat Import](/docs/chat-import) for detailed format-specific instructions and troubleshooting.

## Account Deletion (Article 17 - Right to Erasure)

Permanently delete your account and all associated personal data.

### What Gets Deleted

When you delete your account, the following is permanently removed:

- **Account Information:** Profile, email, authentication data
- **Conversations:** All threads and messages, including temporary threads, thread relationships, invites, shared access, and per-thread variables
- **Files:** All uploaded files, folders, and metadata
- **Documents:** Canvas artifacts and their version history, presentations and their slides
- **Prompts:** All saved prompts and their history
- **Skills:** Your skills, their history, and invocation records
- **Projects and workflows:** All projects, including workflows
- **Pins:** All pinned messages and selections
- **Memories:** Every fact the AI learned about you
- **Settings:** User preferences, AI preferences, and variable defaults
- **Connectors:** Messenger and OAuth connections, browser extension links, and browser automation sessions and logs
- **In-flight state:** Streaming buffers, follow-up suggestions, and chat import jobs
- **Sessions:** All active sessions revoked

### Requesting Deletion

**How to Delete:**
1. Go to Settings → Privacy & Data
2. Click "Delete My Account"
3. Type "DELETE" to confirm
4. Review warning about permanent deletion
5. Confirm deletion

**Deletion Process:**
1. Request submitted with confirmation
2. Deletion workflow begins immediately
3. All data is permanently removed
4. Confirmation email sent
5. Account cannot be recovered

**Important Warnings:**
- ⚠️ **Permanent:** Deletion cannot be undone
- ⚠️ **Immediate:** Data is deleted right away
- ⚠️ **Complete:** All data is removed
- ⚠️ **No Recovery:** Account cannot be restored

**Recovery Period:**
- If you change your mind, contact support within 30 days
- After 30 days, deletion is final
- No data recovery possible after retention period

**Deletion Status:**
- **Pending:** Request submitted
- **Processing:** Deletion in progress
- **Completed:** Account deleted

## Troubleshooting

### Common Issues

**Issue:** Export stuck in "Processing"
- **Solution:** Wait a few minutes - exports can take time
- **Solution:** Check email for completion notification
- **Solution:** Use "Cancel Export" and request new one if stuck

**Issue:** Can't download export
- **Solution:** Check if download link expired (7-day limit)
- **Solution:** Request a new export
- **Solution:** Check email for download link

**Issue:** Deletion not completing
- **Solution:** Check deletion status in settings
- **Solution:** Contact support if stuck
- **Solution:** Verify deletion was confirmed

**Issue:** Consent preferences not saving
- **Solution:** Refresh page and try again
- **Solution:** Check browser settings (cookies enabled)
- **Solution:** Clear browser cache if needed

**Issue:** Can't access privacy settings
- **Solution:** Ensure you're logged in
- **Solution:** Check account permissions
- **Solution:** Try refreshing the page

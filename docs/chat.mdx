# Chat Features

Neore Chat provides powerful AI conversation capabilities with advanced thread management and rich messaging features.

## Quick Start

Get started with Neore Chat in three simple steps:

1. **Create a Thread**: Click "New Chat" or press `Ctrl+N` (Mac: `Cmd+N`) to start a conversation
2. **Choose a Model**: Select an AI model from the dropdown (default: Kimi K2)
3. **Start Chatting**: Type your message and press Enter to send

That's it! Your conversation is saved automatically and you can continue it anytime.

## Core Chat

### Thread-Based Conversations

All conversations are organized into threads, making it easy to manage multiple topics and contexts.

**Features:**
- Create unlimited threads
- Each thread maintains its own conversation history
- Thread titles are auto-generated or can be customized
- Threads can be organized with tags and folders

### Real-Time Message Streaming

Messages stream in real-time as the AI generates responses, providing immediate feedback.

**Features:**
- See responses as they're generated
- Cancel generation at any time
- Smooth streaming experience
- Fast response times

### Message History and Context

Full conversation history is maintained for context-aware responses.

**Features:**
- Complete message history per thread
- Context-aware AI responses
- Message editing capabilities
- Conversation continuity

## Thread Types

Neore Chat supports three distinct thread types, each designed for different use cases. Understanding when to use each type will help you work more efficiently.

:::tip Choosing the Right Thread Type
- **Normal Threads**: For ongoing conversations and projects
- **Temporary Threads**: For quick queries you don't need to keep
- **Stateless Threads**: When you want each message to be independent
:::

### Normal Threads

Standard persistent conversations with full chat history.

**Characteristics:**
- Full chat history maintained across all messages
- Messages have context from previous interactions
- AI can reference earlier messages in the conversation
- Stored permanently until manually deleted

**Best For:**
- Ongoing conversations
- Complex multi-turn discussions
- Projects requiring context
- Important conversations you want to keep

**Features:**
- Can be organized with tags
- Can be pinned to the top
- Can be shared with others
- Can be archived
- Supports thread hierarchy (parent/child relationships)

### Temporary Threads

Auto-expiring conversations with configurable retention periods.

**Characteristics:**
- Default retention: 24 hours (configurable)
- Automatically deleted after expiration
- Can be converted to permanent threads before expiration
- Shown in separate "Temporary" group in thread list

**Best For:**
- Quick, disposable conversations
- Testing or experimentation
- One-time queries
- Temporary research

**Features:**
- Created via "Temporary Chat" button or `Ctrl+Shift+N` (Mac: `Cmd+Shift+N`)
- Display expiration countdown timer
- Convert to permanent before expiration
- Automatically cleaned up after retention period
- Useful for privacy-sensitive conversations

**How to Create:**
1. Click the "Temporary Chat" button in the thread list
2. Or use keyboard shortcut `Ctrl+Shift+N` (Mac: `Cmd+Shift+N`)
3. Start chatting - the thread will auto-expire after the retention period

**Converting to Permanent:**
- Click the "Convert to Permanent" option in the thread menu
- The thread becomes a normal thread and won't expire
- All message history is preserved

### Stateless Threads

Process each message independently without chat history context.

**Characteristics:**
- Each message processed independently
- No chat history context used
- Only system prompt and current input are considered
- Can have custom system prompt for consistent behavior

**Best For:**
- One-off queries where context shouldn't influence responses
- Consistent behavior across messages
- When you want fresh responses each time
- Testing prompts without conversation history

**Features:**
- Shown in separate "Stateless" group in thread list
- Each message gets fresh context
- Can be combined with temporary threads (stateless + temporary)

**How to Enable:**
1. Open thread settings (click model selector)
2. Enable "Stateless Mode" toggle
3. All subsequent messages will be stateless

**Custom System Prompt:**
- Define a system prompt that applies to every message
- Load one from your saved [system prompt presets](/docs/prompts#system-prompt-presets), or optimize the one you have in place
- Works with or without stateless mode
- When used with stateless mode: ensures consistent behavior across messages without chat history
- When used without stateless mode: applies custom instructions alongside conversation history
- Useful for specific use cases or personas

**Combining Thread Types:**
- You can create a temporary stateless thread
- Combines auto-expiration with stateless behavior
- Useful for quick, context-free queries that auto-delete

Switch between models during conversations using multiple methods:

**Method 1: Model Selector**
1. Click the model selector in the composer
2. Choose from available models
3. Continue conversation with new model
4. Previous messages remain in thread

**Method 2: Slash Command**
1. Type `/model` in the composer
2. An autocomplete menu shows available models
3. Type to filter models (e.g., `/model gpt` shows GPT models)
4. Select a model to switch
5. Model changes immediately

**Slash Command Features:**
- Type `/model` to see all models
- Type `/model gpt` to filter GPT models
- Type `/model claude` to filter Claude models
- Favorite models appear first
- Premium models shown only for Pro users
- Keyboard navigation (arrow keys, Enter)

### Favorite Models

Mark frequently used models as favorites:

1. Click the star icon next to a model
2. Favorite models appear at the top of the list
3. Quick access to your preferred models

### Enhanced Model Features

**Reasoning Effort:**
- Configure reasoning effort levels (None, Low, Medium, High)
- Available for models that support reasoning
- Affects response quality and speed

**Extended Thinking:**
- Some models (Claude Opus, Claude Sonnet, DeepSeek R1) support extended thinking mode
- The model shows its reasoning process before the final answer

**Bring Your Own Key (BYOK):**
- Use your own API keys for any supported provider
- Keys are encrypted at rest and never exposed to the client
- Manage keys in **Settings → API Keys**
- Supported providers: OpenAI, Anthropic, Google, OpenRouter, Groq, and more

**Stateless Mode:**
- Enable stateless mode per thread
- Process messages without history
- Custom system prompt support

## Deep Work Mode (Auto-Continue)

Deep Work mode lets the AI run up to 25 tool-use iterations in a single
request — chaining searches, reads, and document creation without
requiring you to send follow-up messages. It's designed for complex
multi-step tasks that would otherwise need back-and-forth.

### Enabling Deep Work mode

Click the **Deep Work** button (lightning bolt icon) in the composer
toolbar before sending your message. When active, the button turns
amber and a label confirms "Up to 25 iterations."

### How it works

When Deep Work mode is on:

1. The AI receives a higher iteration limit (25 instead of the
   default 5).
2. After each step, the system checks whether the context window is
   getting full and compresses older messages if needed.
3. A status bar appears above the composer showing the current
   iteration, tool calls in progress, and a progress bar.
4. You can cancel at any time — partial results are preserved.

### When to use it

| Task type | Deep Work? | Why |
|---|---|---|
| Simple question | No | One step is enough |
| Search + answer | No | Default iterations handle it |
| Multi-step research and report | Yes | Needs many tool calls |
| Trigger-initiated execution | Automatic | All triggers use Deep Work |

### Status bar

While Deep Work is active, a status bar shows:

- Current iteration count (for example, "3/25")
- Number of completed tool calls
- Names of the last three tools executed
- A cancel button to stop early

> **Note:** Deep Work mode uses more tokens per request. For simple
> questions, leave it off.

### Prompt Improvement

Get AI-powered rewrites of your prompt before you send it:

1. Type your prompt, then click the sparkles icon in the composer
2. Pick an optimization style from the dropdown next to it
3. The AI returns a rewritten prompt in a panel
4. Accept it, keep your original, or refine it further with feedback

**Styles:**

| Style | What it does |
|---|---|
| Basic optimization | Quick expression improvement: clarity, structure, missing context |
| Professional precision | Turns a vague request into a specific, actionable one with quantified standards |
| Step-by-step planning | Turns a goal into a structured task plan with role, steps, and output spec |

Your chosen style is remembered between messages.

**Refine with feedback:** the panel has a feedback box. Describe what you want
changed ("make it shorter", "ask for a table instead") and the AI revises its own
previous rewrite rather than starting over.

See [Prompts](/docs/prompts#prompt-optimization) for the full optimizer,
including system-prompt optimization and saved presets.

### Follow-Up Suggestions

After each AI response, Neore Chat automatically generates relevant follow-up questions to help you continue the conversation.

**Features:**
- Automatically generated based on conversation context
- Appears after AI completes a response
- 3-5 contextual suggestions per response
- Click any suggestion to use it as your next message
- Collapsible panel with smooth animations
- Auto-opens on first load, can be toggled closed

**How It Works:**
1. After the AI finishes responding, suggestions appear above the composer
2. Suggestions are contextually relevant to the current conversation
3. Click the chevron icon to expand or collapse the suggestions panel
4. Click any suggestion to insert it into the composer
5. Edit the suggestion or send it as-is

**When Suggestions Appear:**
- Only after AI assistant messages (not after your messages)
- Only when the AI has finished responding (not during streaming)
- Only in threads with at least one user message
- Automatically cached to reduce API costs

**Best Practices:**
- Use suggestions to explore related topics
- Modify suggestions before sending to customize your query
- Suggestions adapt to your conversation's language and context
- Suggestions consider your timezone and location for relevance

### Variable Autocomplete

Insert variables directly in the composer using autocomplete:

**How to Use:**
1. Type `{{` in the composer
2. Autocomplete menu appears with available variables
3. Type to filter (e.g., `{{user` shows user variables)
4. Use arrow keys to navigate
5. Press Enter to insert

**Available Variables:**
- **User Variables**: `{{user.name}}`, `{{user.email}}`, `{{user.organization}}`
- **Context Variables**: `{{context.currentDate}}`, `{{context.currentTime}}`, `{{context.timezone}}`
- **Config Variables**: `{{configs.BRAND}}`, `{{configs.COMPANY}}`, `{{configs.TONE}}`
- **Conversation Variables**: `{{conversation.summary}}`, `{{conversation.history}}`

**Features:**
- Real-time filtering as you type
- Categorized display with icons
- Keyboard navigation (arrow keys, Enter)
- Descriptions for each variable
- Custom variables from prompts appear first

See [Prompts](/docs/prompts) for more information about variables.

2. **Provide Context**: Include relevant background information

4. **Iterate**: Refine prompts based on responses

## Troubleshooting

### Common Issues

**Issue**: Responses are slow
- **Solution**: Try a faster model like GPT-4o Mini or Gemini Flash
- **Solution**: Use stateless mode if context isn't needed

**Issue**: Responses lack context
- **Solution**: Ensure you're using Normal Threads (not Stateless)
- **Solution**: Check that message history is being maintained

**Issue**: Can't find old conversations
- **Solution**: Use the command palette (`Ctrl+K`) or the thread search box (`Ctrl+F`) to find threads
- **Solution**: Check archived threads
- **Solution**: Filter by tags if you used them

**Issue**: Thread expired unexpectedly
- **Solution**: Check if it was a Temporary Thread
- **Solution**: Convert to permanent before expiration

## Canvas (Document Artifacts)

When the AI creates documents, code, spreadsheets, or other artifacts, they
appear in the **Canvas** — a side panel that opens next to the conversation.

**Artifact types:**
- **Text documents** — Rich text editing with ProseKit editor
- **Spreadsheets** — Interactive editing with Univer.js (XLSX import/export)
- **Code** — Syntax-highlighted code with language detection
- **Images** — Generated images from image generation tools
- **Designs** — Editable visual designs (social posts, banners, flyers) on a drag-and-drop canvas
- **Presentations** — AI-generated slide decks with styled templates

**Features:**
- Version history with rollback capability
- Edit content directly in the panel
- Download or share artifacts
- Switch between edit and preview modes

**How it works:**
1. Ask the AI to create a document, spreadsheet, or code file
2. The Canvas panel opens with the generated artifact
3. Edit the content directly in the panel
4. Download or share the result

See also [Spreadsheets](/docs/spreadsheets) and [Design Canvas](/docs/design-canvas)
for artifact-specific features.

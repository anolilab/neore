# Settings

Customize your Neore Chat experience with comprehensive settings for account management, chat preferences, and app customization.

## Quick Start

Access settings from the dashboard navigation or use `Ctrl+,` (Mac: `Cmd+,`) if available.

Settings open in a modal with four groups in the sidebar:

| Group | Pages |
|---|---|
| **App** | Customization, Keyboard Shortcuts |
| **Chat** | Personalization, System Prompts, Knowledge Base, Default Models, Models, Agent, MCP Servers, API Keys |
| **Account** | Account, Security, API Keys, Organizations, Organization, Billing, Members |
| **Privacy** | Privacy & Data |

A few settings pages are not yet listed in that sidebar and are reached by URL:

| Page | URL |
|---|---|
| Triggers | `/dashboard/settings/chat/triggers` |
| Usage | `/dashboard/settings/chat/usage` |
| Model filters | `/dashboard/settings/chat/model-filters` |
| Connectors (messenger) | `/dashboard/settings/connectors` |
| Teams | `/dashboard/settings/auth/teams` |

Separate defaults are configurable for **text**, **image** and **video**. Leaving
one unset falls back to the system default.

### Model Filters

Restrict which models and providers may be used. Reached at

### Usage

Token usage and cost reporting. Reached at `/dashboard/settings/chat/usage` —
this page is not yet linked from the settings sidebar.

**Features:**
- Token usage and cost breakdown per model for a selected period
- Daily spend and request volume
- **Activity** — a calendar heatmap of your replies and spend per day
  over the last 53 weeks. Switch between **Replies** and **Spend** to
  colour the days, and hover a day (or focus the chart and use the
  arrow keys) to see its numbers. A table below lists the same
  activity per month
- **Usage by skill** — replies, tokens and spend per skill or agent
  for the selected period. Replies that used no skill are listed as
  **Assistant (no skill)**
- Budget alerts that notify or block when a usage metric crosses a threshold

**What counts as a reply:** the activity heatmap and the skill
breakdown include every reply the AI wrote for you, not only the ones
in chats you had open. Background runs count too: tasks, triggers,
evals, sub-agents, messenger replies and the Daily Brief (which has its
own row, **Daily Brief**, in the skill breakdown).

**Earlier replies:** replies from before the heatmap existed are added
in the background, once per account — at the latest when you first
open the page. While that runs, the heatmap shows **Adding your
earlier replies…** and fills in as it goes; every reply is counted
once.

### Agent Capabilities

Configure advanced AI agent modules that enhance response quality for complex tasks. Access at **Settings → Chat → Agent Capabilities**.

:::info
The agent loop is always active for all conversations — it provides systematic task execution (analyze → plan → execute → validate). The settings below control optional specialized modules layered on top.
:::

**Task Planning Module**

Breaks complex tasks into numbered steps with progress tracking. The AI will create an explicit plan before executing multi-step work.

- Best for: multi-step development tasks, feature implementation, refactoring, system design
- Enable when: your request has 3+ distinct steps or dependencies between steps

**Knowledge Module**

Applies domain-specific best practices, patterns, and proven approaches to responses.

- Best for: technical work requiring expertise (coding, architecture, data modeling)
- Enable when: you want the AI to follow established patterns and apply professional standards

**Data Source Module**

Prioritizes authoritative sources and validates data quality. The AI cross-references information and is more rigorous about factual accuracy.

- Best for: research tasks, fact-checking, competitive analysis, data gathering
- Enable when: accuracy and source quality matter

**Auto-Detect Task Complexity**

When enabled, the system automatically analyzes your message and enables the appropriate modules — you don't need to configure them manually. Manual module toggles act as a minimum baseline that auto-detection can only add to, never remove.

| Your message | Auto-detected | Result |
|---|---|---|
| "What is 2+2?" | Simple | No extra modules |
| "Build an auth system" | Coding, complex | Planner + Knowledge |
| "Research AI trends" | Research | Knowledge + Data Source |

**Token Cost**

Modules add tokens to each conversation's system prompt (applied once, not per message):

| Configuration | System tokens |
|---|---|
| Base (agent loop only) | ~2,300 |
| + Task Planning | ~2,500 |
| + Knowledge | ~2,600 |
| + Data Source | ~2,700 |
| All modules | ~2,900 |

Enable only what you need — Auto-Detect Task Complexity is the most efficient approach for most users.

### Triggers

Automate agent execution on a schedule, via webhooks, or from external
events. Access at `/dashboard/settings/chat/triggers` — this page is not yet
linked from the settings sidebar.

Each trigger creates a new thread when it fires and runs your configured
agent autonomously with Deep Work mode (up to 25 iterations). Results
appear in your thread list.

**Trigger types:**

- **Schedule** — Run on a cron schedule (for example, daily at 8 AM).
  Uses standard 5-field cron expressions with timezone support.
- **Webhook** — Receive HTTP POST requests from external services
  (Stripe, GitHub, Zapier). Includes HMAC-SHA256 signature
  verification. A unique URL and secret are generated when you create
  the trigger.
- **Event** — React to external events via MCP or Composio (coming in
  a future release).

**Creating a trigger:**

1. Open `/dashboard/settings/chat/triggers`.
2. Click **New Trigger**.
3. Enter a name and optional description.
4. Select the trigger type (Schedule, Webhook, or Event).
5. Configure type-specific settings (cron expression, timezone, etc.).
6. Optionally set a system prompt and input template.
7. Click **Create Trigger**.
8. Enable the trigger with the toggle switch.

**Managing triggers:**

- Toggle triggers on or off at any time.
- View execution count and last triggered timestamp.
- Delete triggers and their execution history.
- Monitor errors — the last error message is shown inline.

> **Note:** Triggers start disabled. You must explicitly enable them
> after creation.

See [Triggers](/docs/triggers) for full documentation including webhook setup and troubleshooting.

## API Keys

### Bring Your Own Key (BYOK)

Use your own API keys for AI providers, search tools, and messenger bots.
Access at **Settings → API Keys**.

**Supported provider keys:**
- **AI providers** — OpenAI, Anthropic, Google, OpenRouter, Groq, and more
- **Search tools** — Tavily (used by web search, people search, company search, deep research)
- **Messenger bots** — Telegram, Slack, and Discord bot tokens

Provider keys are encrypted at rest and decrypted only when needed. This
lets you use your own quotas and billing instead of the platform's.

### API Key Management

**API Keys:**
- Create API keys for programmatic access
- Manage existing keys
- Set expiration dates
- Control access permissions

**Creating API Keys:**
1. Navigate to Settings → API Keys
2. Click "Create API Key"
3. Set name and permissions
4. Copy key immediately (shown once)
5. Store securely

**API Key Features:**
- Prefix: `app_` for application keys
- Metadata: Environment and version info
- Expiration: Optional expiration dates
- Permissions: Scoped access control

**Managing API Keys:**
- View all active keys
- See creation dates
- Revoke keys
- Delete unused keys

**Security:**
- Keys are shown only once at creation
- Store keys securely
- Rotate keys regularly
- Revoke compromised keys immediately

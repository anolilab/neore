# Design Canvas

Ask the AI for a visual — an Instagram story, a LinkedIn banner, an A4 flyer —
and it composes one on a design canvas. The result is not a flat image: every
element stays editable, so you can drag, retype and restyle it afterwards.

## Quick Start

1. Ask for a design, naming the platform and the feel:
   *"Design an Instagram story announcing our launch, bold style"*
2. The canvas panel opens with the composed design
3. Switch to **Edit** mode and adjust anything you like
4. Download it as a PNG

## The editor

Designs open in the canvas side panel. **Preview** mode shows a rendered PNG;
**Edit** mode gives you the full editor.

### Tools

| Tool | What it does |
|---|---|
| **Select** | Move, resize and rotate elements |
| **Text** | Add a text element |
| **Rectangle** | Add a rectangle |
| **Circle** | Add a circle |
| **Line** | Add a line |
| **Pencil** | Freehand drawing |

### Panels

- **Element palette** — shapes, text presets, and image upload
- **Property panel** — edit the selected element's position, size, colour, font and other properties
- **Layer controls** — bring an element forward or send it back

### Keyboard shortcuts

| Shortcut | Action |
|---|---|
| `Delete` | Delete the selected element |
| `Ctrl+Z` / `Cmd+Z` | Undo |
| `Ctrl+Y` / `Cmd+Y` | Redo |
| `Ctrl+C` / `Cmd+C` | Copy |
| `Ctrl+V` / `Cmd+V` | Paste |
| `Ctrl+A` / `Cmd+A` | Select all |

:::note
Shortcuts are suppressed while you're editing text, so `Ctrl+A` selects the text
in the element rather than every element on the canvas.
:::

### Saving

Changes auto-save after a short pause. Each save also regenerates the PNG preview
used in the chat message and in Preview mode.

## Asking the AI to revise a design

You don't have to do every edit by hand. The AI can revise a design in place —
*"make the headline bigger and move it to the top"* — and it can apply image
operations to the canvas itself:

| Operation | What it does |
|---|---|
| **Remove background** | Exports the canvas and strips its background |
| **Upscale** | Exports the canvas at a higher resolution |
| **Style transfer** | Applies an artistic style you describe |
| **Generate element** | Generates a new image from a prompt, to be placed on the canvas |

## Downloading

Use the download button in the canvas panel. Designs export as PNG at the
preset's dimensions.

## Common Use Cases

**Campaign set**
Ask for the same message at several sizes — "an Instagram post, a story, and an
X header for this announcement" — and adjust each by hand afterwards.

**Quick social graphic**
A one-line request gets a correctly-sized, on-style post without opening a design
tool.

**Iterating on a layout**
Let the AI produce a first draft, then move things around yourself. Hand-editing
a decent draft is usually faster than describing every adjustment.

## Troubleshooting

**Issue:** "Design preview unavailable"
- **Solution:** The PNG preview hasn't been generated yet. Open Edit mode and make a change — saving regenerates it

**Issue:** The design is the wrong size
- **Solution:** Name the platform explicitly ("Instagram story", "A4 flyer"), or ask for a custom size

**Issue:** `Ctrl+A` selected my text instead of all elements
- **Solution:** Click empty canvas to leave text editing first

**Issue:** An AI revision replaced work I'd done by hand
- **Solution:** `Ctrl+Z` undoes it. The AI replaces the canvas wholesale when revising, so make manual edits after AI revisions rather than before

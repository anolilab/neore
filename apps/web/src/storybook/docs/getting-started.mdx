# Getting started

This Storybook shows the web app's pages, the base components of `@neore/ui`, the chat components of `@neore/chat-ui`, and the design foundations they share.

## Run it

```bash
pnpm build:packages   # once per fresh checkout: stories import @neore/ai, whose dist is not committed
pnpm storybook        # http://localhost:6006
```

## Find things

- **Foundations**: colours, typography, spacing, radius, shadow, motion. See [Theming](?path=/docs/foundations-theming--docs) for the tokens and the toolbar that switches them.
- **UI**: one folder per component of `packages/ui`, with its states. Every story is one state.
- **Chat**: the AI elements (messages, reasoning, sources, tasks, and the rest) and the chat primitives.
- **Hooks**: the reusable hooks of `packages/ui`, with a live demo where one makes sense.
- **Pages**: the app's real routes, mounted on fake data in each persona.

## Check it

```bash
pnpm test:storybook   # every story, in Chromium, in four modes: light, dark + violet, phone and right-to-left
```

A story passes when it renders, its `play` function passes and axe finds no violation. CI runs the same command.

## Write a story

The rules are in `apps/web/src/storybook/AGENTS.md`. In short: CSF 3 next to the component, `satisfies Meta<typeof Component>`, one story per state that looks or behaves differently, and queries by role and accessible name.

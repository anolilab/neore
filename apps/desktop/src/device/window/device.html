    Terminal
    
                
    
                    A shell on this computer, in its own window, running as you and outside the sandbox below. Nothing you type or see in it is sent to Neore.
                
    
                
    
                
    
                    
                
    

                
    Sandbox
    
                
    Shell commands and local MCP servers run in the same sandbox: they change files only in the shared folders and a private folder of their own.
    
                
                
    
                    
                    
                
    
                
    
                    “Common dependencies only” (macOS) lets a program open HTTPS connections to package registries and source hosts (npm, PyPI, crates.io, Go modules, RubyGems, GitHub),
                    each checked by its TLS server name against the host it was opened for, and nothing else. Those hosts can still receive anything a program sends them.
                    It is not available on Linux, and Windows has no sandbox, so no network setting is enforced there.
                
    
                
    

                
    Servers over SSH
    
                
    
                    Servers this computer speaks for. Add one from Settings → Devices in the Neore app. The server holds no secret of yours:
                    every action is approved here first, then sent down the SSH connection.
                
    
                
    

                
    Local MCP servers
    
                
    
                    Started on this computer when the agent first uses them, inside the sandbox above. Each keeps its package caches in a private folder. Only add commands you trust.

          Coding agents
          
                
          
                    Agents that speak the Agent Client Protocol run on this computer with your rights, outside the shell sandbox. Each one signs in with its own tool;
                    Neore stores no login for it. An agent starts only in a folder you approved for it here. Anything it asks to change prompts you first, once per request; there is no "always allow". macOS and Linux only for now.

            Environment variables
            
                
            
                    Agents start with a minimal environment (PATH, HOME, locale), not a copy of this app's. Add proxy or endpoint settings here. Values are secrets: they stay on this
                    computer, are never sent to Neore, and are shown masked. NEORE_*, ELECTRON_* and NODE_OPTIONS are refused.
